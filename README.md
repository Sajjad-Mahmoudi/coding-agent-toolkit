# code-agent-tricks

Reusable instructions for coding agents.

## AGENTS.md template

The [generic coding-agent template](templates/AGENTS.template.md) provides reusable engineering and specification-documentation policies, plus an agent-maintained Project Profile.

Copy it into your project's root as `AGENTS.md`. Then ask your coding agent to populate and maintain the Project Profile from verified repository facts, preserving the reusable policies.
